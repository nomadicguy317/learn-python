## Tips for Solving Problems

1. **Understand the Problem**: Read carefully and identify inputs, outputs, and constraints
2. **Plan Your Approach**: Think before coding; write pseudocode if needed
3. **Start Simple**: Solve the basic version first, then add complexity
4. **Test Incrementally**: Test your code with sample inputs as you build
5. **Handle Edge Cases**: Consider empty inputs, very large inputs, invalid inputs
6. **Refactor**: Once it works, improve code quality and efficiency
7. **Learn from Solutions**: After solving, compare with other solutions
8. **Practice Regularly**: Consistency is more important than intensity
